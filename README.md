# DataTrust

Ethical Data Infrastructure for the AI Economy.

Phase I establishes the investor experience, presale workflow, protected allocation ledger, audit trail, and the shared product architecture for DataTrust.

## Source of truth

- Product narrative and investor experience: `docs/`
- Financial/token/presale values: `packages/config/`
- Database state and authorization: `supabase/migrations/`
- Application surfaces: `apps/web`, `apps/app`, `apps/admin`

## Phase I boundary

This repository does not claim a production data marketplace, validator network, DAO, enterprise API, browser extension, production data vault, automated on-chain distribution, or full smart-contract presale.

All presale functionality is subject to legal, regulatory, operational, and payment-readiness review before real participant funds are accepted.
